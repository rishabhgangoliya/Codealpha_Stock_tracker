# Stock Portfolio Tracker 📈

## 📌 Description
The Stock Portfolio Tracker is a Python-based project that calculates the total investment value of a stock portfolio using predefined stock prices. Users can enter stock symbols and quantities to calculate individual stock values and the total investment. The application also provides an option to save portfolio results in TXT or CSV format.

## ✨ Features
- Displays available stocks and their prices.
- Accepts stock symbols and share quantities from users.
- Calculates individual stock values and total investment.
- Validates stock names and quantities.
- Handles invalid user inputs.
- Saves portfolio results in TXT or CSV format.

## 🛠️ Technologies Used
- Python 3
- Dictionaries and functions
- Loops and conditional statements
- Exception handling
- File handling

## 🚀 How to Run
1. Install Python 3.
2. Clone this repository:

   ```bash
   git clone https://github.com/rishabhgangoliya/Codealpha_Stock_tracker.git
   ```

3. Open the project folder in VS Code.
4. Run the application:

   ```bash
   python stock_portfolio.py
   ```

5. Enter stock symbols and quantities.
6. Type `done` to finish entering stocks.
7. Choose `txt`, `csv`, or `no` to save or skip saving the results.
